# Theme
## Links
- https://github.com/catppuccin/catppuccin
## Key Shortcuts
- M-46 applies the selected theme to Neovim, Zsh, Zellij, and Ghostty when their config files exist.
## Usage Examples
```sh
grep -n 'MYDOTS_THEME' ~/.config/nvim/lua/plugins/colorscheme.lua ~/.zshrc ~/.config/zellij/config.kdl ~/.config/ghostty/config
```
