# AI Tools

> La IA es una herramienta que aumenta
> la inteligencia humana, no la reemplaza.

## 1. Vibe Coding: olvidate del código, enfocate en la intención

Describí intenciones en lenguaje natural
mientras supervisás el código generado.
Úsalo para boilerplate y prototipos.

**Reglas de Karpathy:**

1. Aceptá imperfección
2. Pensá en alto nivel
3. Iterá rápido
4. Leé el código al menos una vez

## 2. La IA debe aumentar, no reemplazar

Herramientas que potencien al humano y lo
mantengan en el ciclo de decisión.

**Tres Pilares:**

1. Aumentar, no automatizar
2. Humano en el loop
3. Diseñar para la colaboración

## 3. Los modelos grandes tienen responsabilidades

Auditá antes de integrar. Elegí la
herramienta más ética y eficiente.

**Checklist ético:**

- ¿Quién se beneficia?
- ¿Quién resulta dañado?
- ¿Es necesario un LLM para esto?

## 4. El código de IA necesita revisión humana

Verificá seguridad, manejo de errores y
casos borde.

**Checklist IA:**

1. ¿Hay inputs sin validar?
2. ¿Maneja null/undefined/edge cases?
3. ¿Entiendo cada línea?
4. ¿Tests cubren happy, sad, failure,
   chaos?
