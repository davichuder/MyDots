# Security

> La seguridad es un proceso continuo,
> no un checkbox.

## 1. La seguridad es un proceso, no un estado

Disciplina continua en cada decisión
técnica. Validá toda entrada sin excepción.

**Hábito diario:**

1. Validá toda entrada
2. Actualizá dependencias
3. Auditá accesos
4. Modelá amenazas
5. Fallá de forma segura

## 2. La seguridad empieza en el código

Pensá como un atacante. El camino seguro
debe ser el predeterminado.

**Preguntas de diseño:**

1. ¿Qué datos manejo?
2. ¿Quién querría acceder?
3. ¿Lo peor que puede pasar si se filtra?

## 3. Los algoritmos no son neutrales

Los sesgos se incrustan involuntariamente
en los sistemas de IA.

**Preguntas éticas:**

1. ¿Quién está en los datos de
   entrenamiento?
2. ¿Quién falta?
3. ¿Quién sufre los errores?
4. ¿Puedo explicar la decisión?
